Comet Assistant

A personal assistant at home.
Useful answers while out in the world.

Exploring hands-free access to a self-hosted assistant through Meta AI’s native connector platform—without building a separate phone app.

Status: connector planning / seeking developer-preview access

The project

I’m James He. I use Hermes Agent on my own computer, named comet, for personal planning and everyday tasks. This project proposes a narrowly scoped connector so I can access selected assistant functions through Meta AI and my glasses.

The self-hosted assistant is in use. The Meta connector is not built, approved, or publicly available. This page describes the proposed integration, not a working Meta-connected product.

Initial use cases

  • Itinerary questions: ask what is next and retrieve the details needed while traveling.
  • Saved places: find a previously saved restaurant or destination and retrieve its map link.
  • Personal reminders: review reminders and, with explicit confirmation, request new ones.

Proposed connection

Meta AI / glasses → authenticated connector → self-hosted Hermes assistant → response

The planned connector would use Meta’s supported API or MCP onboarding path, subject to developer-preview access and platform requirements. Protocol and authentication implementation are still to be finalized. No public API endpoint or API documentation is available yet.

Privacy by design

The intended design exposes only selected tools, not unrestricted computer or terminal access. Account linking, limited permissions, and explicit confirmation for state-changing actions are design goals, not implemented guarantees.

This informational page contains no private itineraries or account data, uses no analytics or cookies, and collects no form submissions. Hosting infrastructure may process ordinary request metadata. Any future connector’s data handling will be documented before testing.
